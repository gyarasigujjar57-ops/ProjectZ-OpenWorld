# Character assets

The player controller expects these two rigged GLB files:

- `character_1_teen.glb`
- `character_2_cyborg.glb`

Place both files in this folder (`res://assets/`). They must be the original binary GLB models with their embedded skeletons and animations.

**Status:** The source GLB files are not currently available to this workspace, so they have not been added. Do not replace them with empty or renamed placeholder files.

Once the originals are supplied to the build workspace, commit them here and run the Android export workflow.
