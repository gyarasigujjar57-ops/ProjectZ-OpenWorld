# Project Z: Open World Prototype

An early Godot 4.x scaffold for an original third-person open-world Android game concept.

## In this starter
- A large flat 5.5 km x 5.5 km world footprint
- Placeholder Rajasthan-inspired village/dunes, city blocks, industrial area, railway yard and bridge
- Third-person capsule character and follow camera
- Basic keyboard movement, sprint, jump and mouse-look
- Simple starter target script

## Honest status
This is **not a finished game or APK**. The world uses simple placeholder geometry, not production-quality 3D assets. Vehicles, touch controls, detailed animations, mission systems, NPC routines, police/gang AI, advanced combat, save system and Android export are not implemented. The project has not yet been validated by running it in Godot, so treat it as an untested starter.

## Run
Open this repository as a project in Godot 4.x and run the main scene. Desktop keyboard input is the current prototype control scheme; Android touch controls still need to be added.
